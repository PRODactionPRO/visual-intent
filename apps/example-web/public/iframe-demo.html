Проверка выбора внутри iframe

Здесь можно проверить доступный iframe и безопасный fallback, когда Chrome не получил разрешение на сторонний origin.

Same-origin iframe

Выберите синюю кнопку внутри карточки.

Cross-origin iframe

Разрешите origin, чтобы выбрать кнопку внутри, или отклоните запрос, чтобы выбрать внешний контейнер iframe целиком.
